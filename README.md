Templates for [Obsidian Web Clipper](https://github.com/obsidianmd/obsidian-clipper). 

To install templates, see instructions in the [official Obsidian Web Clipper documentation repo](https://help.obsidian.md/web-clipper/templates).

Started with [kepano's template](https://help.obsidian.md/web-clipper/templates) with some customisation and modification.
